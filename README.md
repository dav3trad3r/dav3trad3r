## Featured: agentPickup

[![agentPickup](https://agentpickup.app/og.png?v=2)](https://agentpickup.app)

**[agentpickup.app](https://agentpickup.app)** is commerce and fulfilment infrastructure that lets AI agents buy from physical
businesses. Agents find a business, read its catalogue, ask questions and place an order. The order lands in the system the
business already runs, and the customer collects in person with a signed pickup pass. It works in any industry and with any
point of sale, and the money goes straight to the business.

- **For agents:** an MCP server for Claude, ChatGPT and other assistants, plus support for the agent commerce standards UCP, ACP and MPP
- **For businesses:** orders arrive on their point of sale next to their other orders, with a dashboard for sales and what people ask about them
- **Verified collection:** a signed QR pickup pass that staff can check offline
- **Open parts:** the pickup-pass format, the MCP server and an agent skill in [agentpickup-sdk](https://github.com/Tokenise-au/agentpickup-sdk), published on npm and in the official MCP Registry
